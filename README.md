## Featured project

**ARCHÉGOLD Command Center** is a dark, mobile-ready AI workspace for chat, system prompts, quickfire actions, OpenRouter model access, cloud synchronization and snapshot-based workspace recovery.

Live demo: https://kiworkdash-mmeulqdy.manus.space

## Quickstart for testers

1. Open the live demo and sign in with the available authentication flow if you want cloud synchronization and workspace snapshots.
2. Start a chat or use one of the quickfire actions in the Command Center.
3. Choose a System-Prompt-Profil such as Research Analyst, Code Forge or Security Sentinel.
4. Open Archiv or press Ctrl+K, then run /archive to inspect saved workspace snapshots and restore an earlier configuration.
5. The application routes model requests through OpenRouter; testers need their own authorized access and should not share API keys in chat, issues or screenshots.

The public app listing is proposed through the [OpenRouter app-directory pull request](https://github.com/NUMEN1156/awesome-openrouter/pull/1).
